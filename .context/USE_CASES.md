## Intelligence Use Cases (AI-Driven)

| ID | Use Case | What AI Does | Data Needed |
|----|----------|--------------|-------------|
| AI-01 | Optimal Utilization Target | Learns from history to suggest right target | 6+ months |
| AI-02 | Predictive Bench Alert | "John will likely be on bench in 45 days" | Current allocations |
| AI-03 | Smart Resource Matching | ML scoring for skills, availability, fit | Skills + allocations |
| AI-04 | Demand Forecasting | "You'll need 5 more Java devs in Q2" | Pipeline + history |
| AI-05 | Anomaly Detection | "Project X has unusual resource churn" | 3+ months history |
